# Changelog

## 1.1.0

A redesign of the control panel. Nothing new is collected or requested: the permissions are the same as 1.0.0.

### Added
- **Wall view.** The screens are drawn as a map of your display in the real layout. Click a screen for sound, drag a screen onto another to swap, drag a site from the list onto a screen to open it there.
- **Wall / Edit switch** above the screens. Edit view keeps the per-screen cards with the link box, Back/Forward, recent pages and Swap. The panel remembers the choice.
- **1–4 keys** in the panel move the sound.
- **Tidy YouTube tip.** Putting youtube.com on a screen while Tidy YouTube is off offers to turn it on, once per screen, with **Don't ask again**.

### Changed
- New look: one line-icon set instead of emoji and text arrows, neutral colors for selection, and amber used only to mark the screen with sound. The toolbar icon follows suit.
- **Snap**, **Mute all** and **Close all** moved into a **⋯** menu in the header. Close all asks for a second click instead of a browser dialog.
- Saved views moved below the screens.

### Fixed
- Notifications at the bottom of the panel had lost their styling.
