# Code of Conduct

This project is open to everyone. Contributors and maintainers commit to making it a respectful, harassment-free place to take part, whatever someone's background, identity or level of experience.

## Expected

- Be considerate and patient, especially with people new to the project.
- Discuss the code and the idea, not the person.
- Accept review comments and decisions gracefully, and give them constructively.

## Not acceptable

- Harassment, insults, or discriminatory or sexual language and imagery.
- Personal or political attacks, trolling, and deliberately derailing discussions.
- Publishing anyone's private information without their permission.

## Enforcement

Maintainers may edit or remove comments, commits, issues and pull requests that break this code, and may block people who keep doing so.

To report a problem privately, use the contact details on the maintainer's GitHub profile, or the **Report content** option GitHub offers on every comment. Reports are kept confidential.

This code applies in all project spaces, including issues, pull requests and discussions.
