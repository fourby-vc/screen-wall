# Security

If you find a security or privacy problem in this extension, please report it privately rather than in a public issue.

Use GitHub's **Report a vulnerability** button on this repository's **Security** tab (private vulnerability reporting).

Please include the extension version (Settings → About), your Chrome version and the steps to reproduce. You'll get a reply as soon as the report has been looked at.

The extension has no servers and makes no network requests of its own, so reports are usually about the extension's pages, its handling of imported backup files, or the links it opens.
